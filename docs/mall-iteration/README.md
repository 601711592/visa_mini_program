## 登录改造：静默登录（2026-10-10）

- 老会员不再每次授权手机号：启动时本机没有 token 或 token 已过期，自动用 `wx.login` 的凭证调用 `POST /auth/login` 登录。只有确认尚未注册的微信身份才需要在登录页勾选协议并授权手机号。
- 已登录时回到前台不再重新校验，也不清空会员资料；之后任一接口返回 401 才清理登录态，下次需要登录时自动静默登录。启动校验遇到网络失败保留 token 并提示可重试，不当作失效。
- 主动退出后记在本机，不再自动登录；登录页显示“微信一键登录”，老会员点一下即可，不需要手机号。未注册时页面切换为手机号授权。
- 删除 `wx.checkSession` 和 `/auth/wechat-session` 校验。
- 尚未处理：使用过程中 token 恰好过期时，当次请求仍会失败并提示登录已失效，下一次进入需要登录的页面时自动恢复；没有做请求级的自动重试。

`tests/auth.test.cjs` 相应调整：新增 6 项，原微信会话校验 1 项改为 token 过期后静默登录。编写环境没有 Node 运行时，测试未执行。后端接口、会话存储和限流改动见后端 `docs/mini-auth.md`，两端需一起发布。
